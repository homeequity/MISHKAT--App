# GitHub APK Builder Template

قالب GitHub قابل لإعادة الاستخدام لبناء تطبيق Android من ملف ZIP وإنتاج APK عبر GitHub Actions.

## طريقة الاستخدام

1. أنشئ مستودع GitHub جديدًا باستخدام هذا القالب أو ارفع محتوياته إلى مستودع فارغ.
2. ضع ملف مشروعك المضغوط داخل مجلد `input/` وسمّه `project.zip`.
3. ارفع التغييرات إلى GitHub.
4. افتح تبويب **Actions** ثم اختر **Build APK** ثم **Run workflow**.
5. انتظر انتهاء البناء وافتح تشغيل workflow الناجح.
6. نزّل ملف `app-debug.apk` من قسم **Artifacts**.

## ما الذي يدعمه؟

- مشاريع Android الأصلية التي تحتوي على `gradlew` وملفات Gradle.
- مشاريع Flutter التي تحتوي على `pubspec.yaml` ومجلد `android/`.

يحاول workflow اكتشاف نوع المشروع ومجلده تلقائيًا، ثم يبني نسخة Debug.

## ملاحظات مهمة

- هذا القالب لا يحوّل أي ZIP عشوائي إلى تطبيق؛ يجب أن يحتوي ZIP على مشروع Android/Flutter صالح وقابل للبناء.
- إذا كان المشروع يحتاج مفاتيح توقيع أو متغيرات سرية أو إعدادات خاصة، فيجب إضافتها بشكل آمن إلى GitHub Secrets وتعديل workflow.
- الناتج Debug APK للاختبار والتثبيت، وليس إصدارًا موقّعًا للنشر على Google Play.
- إذا احتوى ZIP على أكثر من مشروع أو كانت بنيته غير معتادة، فقد تحتاج إلى ضبط مسار المشروع في `scripts/build.sh`.
